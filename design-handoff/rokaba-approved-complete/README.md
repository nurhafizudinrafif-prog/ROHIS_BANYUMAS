# ROKABA — Paket referensi desain lengkap
Buka **index.html** di browser untuk melihat seluruh gambar berurutan. Klik gambar untuk ukuran penuh.

## Isi paket
- 15 gambar PNG bernomor, mencakup halaman/bagian publik, admin, HP, dialog dan komponen.
- RANCANGAN-LENGKAP.md: cakupan, tata letak, bahan kaca, responsif, dan catatan konten.
- PROMPT-ANTIGRAVITY.md: prompt implementasi.
- PROMPTS-GAMBAR.json: prompt gambar dan referensi yang dipakai.
- references/: tiga gambar pilihan asli.
- assets/: dua dokumentasi asli dari website, logo, serta tiga aset potret yang sudah ada di proyek.

## Cara menggunakan
1. Tinjau gambar di galeri dan baca keputusan desain.
2. Bawa seluruh folder ke Antigravity, bukan hanya satu screenshot.
3. Gunakan PROMPT-ANTIGRAVITY.md beserta AGENTS.md proyek.
4. Data dan fungsi aktual mengalahkan contoh dalam gambar.
5. Gunakan aset asli, bukan hasil crop foto/logo dari gambar AI.

Potret proyek bukan konfirmasi identitas pengurus saat ini. Bila sumber data belum memiliki foto,
gunakan placeholder yang jujur. Gambar statis tidak membuktikan animasi kaca sudah diimplementasikan.
Paket ini tidak mengubah source website, akun, database, atau deployment.
